# Источники каталога

Каталог теперь генерируется из всей базы в `data/vehicles`, а не из восьми вручную внесённых карточек.

- Реестр всех записей: [data/INVENTORY.md](data/INVENTORY.md).
- Полный отчёт и потерянные ссылки: [data/import-report.json](data/import-report.json).
- Правила структуры, статусы и ограничения: [data/README.md](data/README.md).
- Для каждой записи точные публикации и SHA-256 оригиналов фотографий сохранены в её `sources.json`.
- Повторы объединены только явно заданными правилами; неуверенные совпадения сохранены для проверки.
- Источник — предоставленный владельцем экспорт канала «Авто || ПараLLель» от 18.10.2026. Оригинал целиком сохранён локально, не опубликован.

Сведения продавца не подтверждают техническое состояние, наличие, стоимость сегодня или законность конкретного варианта импорта. Описания из новостей, подборки без точной идентификации, групповые предложения и отсутствующие видео не превращены в проверенные товарные предложения.
