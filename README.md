# Авто || ПараLLель

Адаптивный сайт автомобильного агентства. HTML, CSS и JavaScript; без браузерных зависимостей, аналитики и внешних шрифтов. Публикуется на GitHub Pages.

## Запуск и сборка

Node.js 22+. Установка пакетов не требуется.

```sh
npm run dev
npm run build
```

Или напрямую: `node scripts/serve.mjs` и `node scripts/build.mjs`. Предпросмотр — http://127.0.0.1:4173. Сборка читает `data/vehicles`, генерирует каталог, проверяет ресурсы, ID и якоря, создаёт `dist/`. Корневой `catalog-data.js` генерируется для GitHub Pages и должен коммититься после изменения JSON.

## Данные

Полная инструкция: [data/README.md](data/README.md). Реестр: [data/INVENTORY.md](data/INVENTORY.md). Отчёт: [data/import-report.json](data/import-report.json).

- 90 записей из всего предоставленного экспорта, по папке на запись: марка → модель → постоянный ID.
- История цен и статусов, точные исходные публикации, связь фотографий с оригиналами.
- 81 запись опубликованы в каталоге; 9 неоднозначных записей оставлены для проверки. Это количество записей, не подтверждённый склад.
- Проданные доступны отдельным фильтром. В каталоге есть поиск на русском и латиницей, сортировка, порционная выдача и прямые ссылки.
- 827 сообщений и 618 оригинальных фото учтены без потерь. Оригинальный экспорт сохранён локально в `.local-source/`, которая исключена из Git и публикации.
- SQLite-индекс: `python scripts/rebuild-database.py`. Основной источник — JSON; SQLite пересоздаётся и не публикуется.

## Публикация

Settings → Pages → Deploy from a branch → main → / (root). Все пути относительные. Адрес: https://ydhpftyh4c-alt.github.io/avto-parallel-demo/.

`dist/` содержит готовую статическую сборку. Для обычного хостинга достаточно выгрузить её. Полные оригиналы экспорта, SQLite, новости и материалы на проверку не требуются браузеру. GitHub Pages публикует содержимое выбранной ветки, поэтому **никогда не коммитьте `.local-source/`, секреты или персональные данные заявок**.

## Подробные условия поиска

Раздел «Бюджет, год и пробег» раскрывается по нажатию и автоматически раскрывается для активных параметров из ссылки. URL-параметры: `budget`, `yearFrom`, `kmTo`. Бюджет фильтрует только известные RUB-цены, включая стартовые значения «от»; это не обещание окончательной стоимости. Год и пробег берутся из `specs.year` и `specs.mileage_km`. При правке JSON обновляйте нормализованные поля вместе с отображаемыми подписями.

В карточке есть сворачиваемая история цены. Временные акции и альтернативные комплектации имеют отдельные подписи; отметка о продаже содержит дату сообщения из канала. Браузер получает только нормализованную историю, а не полные тексты экспорта.
