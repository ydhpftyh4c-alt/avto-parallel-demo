# Авто || ПараLLель

Адаптивный сайт агентства. HTML, CSS и JavaScript без зависимостей, сторонних скриптов, аналитики и удалённых шрифтов.

## Разработка

Node.js 22+. Установка пакетов не нужна. `npm run dev` открывает сервер http://127.0.0.1:4173. `npm run build` проверяет синтаксис, ресурсы, якоря и уникальность ID, создаёт `dist/`.

## GitHub Pages

Settings → Pages → **Deploy from a branch**, **main**, **/ (root)** → Save. `.nojekyll` отключает Jekyll. Все пути относительные. Адрес после успешной публикации: https://ydhpftyh4c-alt.github.io/avto-parallel-demo/.

## Функциональность

Фильтры каталога по категории и стране марки (не стране поставки), выбор модели в форму, мобильное меню, навигация с клавиатуры, aria-live и reduced motion.

Конструктор бюджета: цена × введённый пользователем курс + логистика + услуги + платежи. Все поля обязательны. Пустые и отрицательные значения не дают итог; смена валюты очищает курс. Нет встроенных ставок пошлин, утильсбора или курса. Возможность импорта и полнота расходов не проверяются.

Демоформа проверяет ввод и показывает результат на странице. Нет CRM, сетевой отправки, cookies или localStorage. Ввод остаётся в памяти текущей страницы.

## Перед коммерческим запуском

1. Заменить временный `assets/mark.svg` оригинальным логотипом. Знак создан по текстовому описанию, это не восстановленный оригинал.
2. Подтвердить географию поставок, перечень услуг, контакты, реквизиты и условия договора.
3. Заменить демонстрационные модели реальными предложениями, проверенными фото и характеристиками. Наличие, стоимость и возможность импорта сейчас не подтверждены.
4. Фото иллюстративные и могут не соответствовать указанной модели. Заменить собственными снимками предложений; источники в `ASSETS.md`.
5. Подключить серверный приём заявок, валидацию и защиту от спама. Подготовить политику обработки данных, согласие и проверить требования к размещению данных с профильным специалистом. Затем убрать режим демоформы.
6. Добавить подтверждённые кейсы и документы. На сайте нет вымышленных отзывов, гарантий, адресов и статистики.

Сборка проверяется GitHub Actions при push и pull request. Результаты проверки интерфейса — в `QA.md`.
