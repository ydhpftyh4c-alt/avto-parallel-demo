# Админка «Авто || ПараLLель»

## Локальный запуск

Из корня проекта:

```sh
node server/index.mjs
```

Или дважды нажмите `Start-Admin.cmd` в Windows. Требуется Node.js 22.13+, предпочтительно установленная у нас версия 24. Зависимости устанавливать не нужно. Кнопка запуска использует Node из PATH или имеющуюся среду Codex. Не закрывайте окно процесса во время работы.

- Админка: http://127.0.0.1:4181/admin/
- Сайт с изменениями из базы: http://127.0.0.1:4181/

При первом входе самостоятельно задайте логин и пароль от 12 символов. Постоянный пароль заранее не задан; тестовые учётные записи в вашу базу не добавляются. Первичная регистрация через браузер разрешена только на localhost. Администратор один, сессия действует 12 часов. Пароли хранятся в виде scrypt-хеша с солью, сессии — в виде хеша случайного токена. Cookie HttpOnly, SameSite=Strict, с Secure при HTTPS; изменения требуют CSRF-токен и точный Origin. Не выставляйте локальный HTTP-порт напрямую в Интернет.

Реальные записи и настройки — `.admin-data/admin.sqlite`, загруженные изображения — `.admin-data/uploads/`, резервные копии базы — `.admin-data/backups/`. Эта папка исключена из Git и не обслуживается статическим сервером. Исходная папка `vehicle-library/` также сохранена. При запуске админка читает найденные локальные полные галереи поставщиков; в разделе «Загрузчики» есть кнопка повторного чтения галерей.

## Управление объявлениями

1. Найдите автомобиль по названию или нажмите «Добавить автомобиль».
2. Измените характеристики, описание и цену в нужной валюте.
3. Загрузите фотографии или нажмите «Заменить» у конкретного снимка. Первый кадр — обложка. Порядок меняется перетаскиванием либо стрелками, в том числе с клавиатуры.
4. Выберите «Черновик», «На сайте» или «В архиве» и сохраните.

Без фотографии, названия и марки публикация невозможна. Удаление кадра из объявления не удаляет файл оригинала. Фото принимаются только в JPG, PNG, WebP и AVIF с проверкой сигнатуры, до 12 МБ каждое, до 100 кадров на объявление; SVG и HTML не принимаются. Имена загруженных файлов заменяются случайными UUID.

Правки хранятся отдельно от импортированных данных. Новая выгрузка меняет исходник, сохраняя отредактированные вами поля и фотографии. Если запись изменилась, пока редактор был открыт в другой вкладке или во время импорта, сервер отклонит сохранение старой версии; откройте запись заново. История позволяет вернуть прежние ручные правки. Новые импортированные автомобили попадают в черновики. Отсутствие автомобиля в частичной/неудачной выгрузке не удаляет имеющуюся запись и не означает продажу.

У опубликованных записей изменения сразу видны на сайте **этого сервера**. Это не меняет автоматически текущую версию на GitHub Pages.

## GitHub Pages

Настройки → «Сохранить изменения в проект» экспортирует только опубликованные карточки и необходимые фотографии в `data/admin-catalog.json` и `assets/buyer-photos/admin/`. Для черновиков/архива экспортируется только ID и статус, без приватного текста и фотографий. Сборка применяет экспорт поверх исходного каталога.

```sh
node scripts/build.mjs
```

После проверки нужна обычная публикация изменений в GitHub. Админка не хранит GitHub-токен в браузере и не выполняет автоматический push. Пока сервер размещён только на вашем компьютере, удалённые покупатели продолжают пользоваться сохранённой версией GitHub Pages. Для самостоятельной немедленной публикации из админки нужен постоянно работающий сервер с основной версией сайта.

## Ночные задания

Расписание по умолчанию включено: **02:00–06:00, Москва**. Его можно изменить или выключить в настройках. Оно начинает действовать после создания администратора и работает только пока сервер запущен и компьютер не спит. Закрытие браузера не мешает, выключение компьютера останавливает работу. Это серверный планировщик; задания Codex и системное расписание Windows не создавались.

За ночь создаётся одна очередь:

1. Проверка доступа площадок.
2. Снимок доступной выдачи LOTTE.
3. Публичное окно mobile.de — не более 50 страниц, частичная полнота сохраняется явно.
4. Полные галереи и скачивание фотографий имеющихся записей.

Одновременно работает один управляемый процесс. Ранее запущенная внешняя загрузка отображается отдельно; новые задания ожидают её завершения. В конце ночного окна запланированный процесс останавливается с состоянием «До следующей ночи»; следующей ночью продолжает работу, пропуская сохранённые галереи и фотографии. Сетевой сбой или изменение разметки записываются как ошибка; следующая ночь запускает новую попытку. Незавершённый проход mobile.de сохраняет промежуточные данные отдельно и не заменяет предыдущий снимок.

Наличие проверок доступа Encar/Che168 остаётся ограничением. CAPTCHA, блокировки, авторизация и HTTP 403/429 не обходятся. Полное зеркало всех четырёх платформ не заявляется. Суммы пошлин, утильсбора и курса валют автоматически не выдумываются.

**Подключена локальная обработка LaMa + OCR.** В настройках есть переключатель автоматической ночной обработки. Подходящие снимки заменяются автоматически; остальные доступны в свёрнутых исключениях. Подробности и ограничения — [PHOTO-AUTOMATION.md](PHOTO-AUTOMATION.md).

## Резервные копии

Кнопка в настройках скачивает согласованную SQLite-копию с объявлениями, историей, учётной записью и настройками. Также копия базы создаётся перед ночным циклом, в `.admin-data/backups/`. Храните её приватно: она содержит данные администратора. Файлы фотографий в копию базы не включаются — отдельно сохраняйте `.admin-data/uploads/`, исходные `vehicle-library/` и публичные фото проекта. Автоматическая выгрузка резервных копий на другой сервер и ротация пока не настроены.

## Перенос на сервер

Внешний сервер и домен ещё не подключены. Ниже — подготовленная схема, а не сообщение о состоявшемся развёртывании.

1. Подготовьте Linux-сервер с Node.js 24, доменом и HTTPS. Сайт и админка должны работать на одном origin.
2. Разместите код проекта в `/opt/avto-parallel-demo`, создайте отдельного пользователя `avto` и предоставьте ему доступ к каталогу проекта: загрузчики сохраняют там снимки и локальную библиотеку.
3. Остановите локальный сервер. Перенесите целиком `.admin-data/` в `/var/lib/avto-parallel` и исходную библиотеку в `vehicle-library/` серверного проекта. Тогда сохранятся логин, пароль, фотографии, правки и уже загруженное. Обычный `git clone` приватные файлы не переносит.
4. Ограничьте доступ к приватному каталогу пользователем сервиса. Скопируйте `deploy/environment.example` в `/etc/avto-parallel.env`, задайте реальный HTTPS-адрес в `ADMIN_ORIGIN` и `PUBLIC_SITE_URL`, путь `ADMIN_DATA_DIR`. В примере нет паролей.
5. Установите и адаптируйте `deploy/avto-parallel.service.example` как systemd-службу. Проверьте путь к Node. После запуска служба будет восстанавливаться при сбое и работать без открытого окна браузера.
6. Настройте HTTPS reverse proxy по образцу `deploy/nginx.conf.example`. Пример содержит заглушки домена и сертификатов — замените их. Node слушает только `127.0.0.1:4181`; proxy должен сохранять Host. Без корректного HTTPS-origin сервер откажет в удалённой настройке.
7. Проверьте вход, загрузку фото, публикацию, резервную копию и ночное задание на сервере. Затем переключите основной адрес сайта на сервер. На GitHub Pages остаётся статическая версия, которая самостоятельно выполнять backend не умеет.

Текущая база — SQLite в режиме WAL: полноценное постоянное хранение для одного серверного экземпляра. PostgreSQL и внешнее объектное хранилище из первоначального предложения здесь ещё не подключены. Для нескольких серверов или каталога в миллионы записей потребуется следующая стадия архитектуры с серверным поиском и пагинацией покупательского каталога. Примеры systemd/nginx подготовлены, но на внешнем хостинге ещё не проверены.

## Проверки

```sh
node --test server/admin.test.mjs server/jobs.test.mjs server/import.test.mjs
node scripts/build.mjs
```

Тесты используют временные базы и отдельные тестовые учётные записи. Проверяют авторизацию, CSRF/Origin/Host, загрузку файлов, черновики, историю, конкурирующее сохранение, сохранность правок при импорте, резервную копию, экспорт без приватных черновиков, перезапуск, очередь, ночное расписание, остановку и атомарность прерванного импорта. Они не запускают реальный сбор сторонних площадок и не отправляют тестовые объявления на публичный сайт.
# Обработка фото

Подключён локальный обработчик LaMa + OCR. В **Настройках** есть один переключатель автоматизации и свёрнутые исключения. По замеру RTX 2060 SUPER включён бюджет до 2 000 фото на ночное окно. Инструкция: [PHOTO-AUTOMATION.md](PHOTO-AUTOMATION.md). Для полного бэкапа кроме SQLite сохраняйте `.admin-data/retouch/` и `.admin-data/uploads/`.
