# Площадки поставщиков — 20.10.2026

Пользователь подтвердил четыре площадки: mobile.de, Encar, Che168 Global и LOTTE Auto Global. API и выгрузки поставщики предоставить не могут. Автоматическая загрузка объявлений не подключена; это ограничение отражено в интерфейсе.

## Что действительно загружено

`data/import/reference/mobile-de.json` — 185 марок и 2511 названий моделей из публичного официального справочника mobile.de. Не включает технический пункт «Other». Это справочник наименований, включая исторические автомобили, а не объявления, комплектации, подтверждённые маршруты или наличие. Названия зависят от региона; справочник не охватывает все модели китайского и корейского рынков.

Обновление вручную: `node scripts/fetch-mobile-reference.mjs`. Скрипт обращается только к документированным reference API, последовательно, с паузой между запросами, тайм-аутом и остановкой при ошибке. Файл заменяется после успешной полной загрузки. Обновление затем проходит обычную сборку и публикацию. Расписание не создавалось.

Документация: https://services.mobile.de/docs/search-api.html — reference endpoints без аутентификации; объявления Search API требуют отдельного активированного доступа.

## Проверенные ограничения

- mobile.de: справочник доступен, Search API объявлений требует доступа. Полный каталог объявлений не получен.
- Encar: главная перенаправляет на страницу ограничения автоматического доступа. Обход не выполнялся.
- Che168: обычный HTTP возвращает страницу проверки бота вместо каталога. Обход не выполнялся.
- LOTTE: главная доступна, но статьи 13(viii), 15(2) условий требуют предварительного согласия на автоматизированный сбор и коммерческое воспроизведение. Объявления и фотографии не перенесены: https://m.lotte-autoglobal.net/co/main/popSpltInfoView.do?mode=20.

Исходные технические пробы находятся только в игнорируемой `.local-source/suppliers/`; они не публикуются. Статусы интеграций хранятся в `data/import/providers/registry.json`. Универсальный импортёр авторизованных JSON-выгрузок остаётся подготовленным, но реальных поставщицких выгрузок нет.

## Действующий пользовательский сценарий

В каталоге раскрывается блок поставщиков. Справочник подгружается только при открытии. Выбор марки ограничивает список моделей. Можно перейти на площадку и вставить ссылку на конкретное объявление. Система определяет источник и направление по разрешённому домену, сохраняет ID объявления, удаляет известные рекламные метки. HTTPS, отсутствие учётных данных и точное совпадение домена проверяются; похожие домены отклоняются.

Кнопка формирует редактируемый текст обращения и переносит модель, направление и пользовательский бюджет в существующий локальный черновик. Это не отправка в CRM, не импорт объявления и не проверка его существования. Цена продавца и сумма с доставкой автоматически не рассчитываются. Без модели разрешён запрос только по ссылке.

Код: `supplier-engine.mjs`, `suppliers.js`. Проверки сценариев и ссылок: `node scripts/check-suppliers.mjs`, входят в общую сборку. Данные агентства из Telegram и прежний справочник моделей сохраняются отдельно.
