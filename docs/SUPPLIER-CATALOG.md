# Каталог поставщиков — 20.10.2026

На сайте работает `order.html` — каталог конкретных автомобилей под заказ. Основная навигация, первый экран и вкладка каталога ведут в него. Прежние объявления агентства и справочник моделей остаются отдельно.

## Реально загруженные данные

LOTTE Auto Global: 4950 уникальных объявлений, 31 марка, 495 страниц. У каждого объявления есть фото (до пяти ссылок), цена продавца в USD или отсутствие цены, год, пробег, двигатель и другие предоставленные поля, ID и прямая ссылка на оригинал. Публикуются только выбранные поля автомобиля: VIN, ID продавцов и полный сырой ответ не включены в каталог.

- `data/import/listings/lotte.json` — нормализованный снимок источника.
- `order-catalog.json` — публичная проекция, которую читает сайт; около 4,54 МБ, около 374 КБ при gzip.
- `.local-source/suppliers/lotte-pages/` — исходные ответы 495 страниц, игнорируются Git и не публикуются.
- `data/import/providers/access-report.json` — фактические результаты проверок других источников.

Снимок сообщает начало и завершение обхода, время получения каждого автомобиля, ожидаемый размер выдачи, число страниц и уникальных записей. Записи не считаются подтверждённым наличием или возможностью ввоза. Публикации могут изменяться во время обхода. При обновлении старый снимок заменяется полностью только после успешного завершения: исчезнувшее объявление не объявляется автоматически проданным.

## Парсер и обновление

`npm run import:suppliers` или `node scripts/sync-suppliers.mjs`:

1. Проверяет источники без учётных данных и обхода ограничений.
2. Обходит общедоступный постраничный список LOTTE по тому же запросу чтения, который вызывает публичный каталог: POST `https://m.lotte-autoglobal.net/by/buy/selectGdListAjax.do`, поле `pageIndex`. Эта операция получает список, не создаёт заявки и не совершает покупку.
3. Проверяет структуру ответа, номера и повтор страниц, безопасные ID (включая реальные ID с префиксом U), числовые значения и пути фото.
4. Записывает нормализованный снимок атомарно и генерирует публичный JSON.

Запросы последовательные, пауза 300 мс после каждого ответа, тайм-аут 30 секунд. При HTTP-ошибке, проверке доступа, изменении схемы или неожиданной странице импорт прекращается. Повторного обхода блокировок, прокси, подделки сессий и решения проверок нет. Незавершённый импорт не заменяет прежний снимок.

Для восстановления после ошибки нормализации без повторных сетевых запросов: `node scripts/parse-supplier-listings.mjs --from-cache`. Нужны все страницы локального кэша не старше суток; исходные времена загрузки сохраняются. Затем `node scripts/build.mjs`, проверка и обычная публикация. Расписание не создавалось; импорт не выполняется при сборке CI и посещении сайта.

Фото запрашиваются браузером с CDN LOTTE, водяной знак сохраняется. Это не копии в репозитории. Недоступное фото заменяется нейтральной иллюстрацией с соответствующей подписью. Карточки показываются по 24, фотографии загружаются лениво.

## Остальные площадки

- mobile.de: API объявлений вернул HTTP 401. Справочник 185 марок / 2511 названий моделей уже загружен через открытые reference endpoints, но это отдельные данные, не объявления.
- Encar: HTML главной и поиска доступны обычным запросом. Публичный JS указывает на `https://api.encar.com/search/car/list/general`; запрос к нему вернул HTTP 404 с перенаправлением на `has_been_cr_blocked_AWS.html`. Объявления не получены. Блокировку не обходили.
- Che168 Global: вместо каталога возвращается страница проверки доступа. Объявления не получены.

Таким образом, загружен полный постраничный срез LOTTE на момент обхода, а не все объявления всех четырёх площадок. Статусы показаны посетителю. Условия LOTTE, найденные при исследовании, остаются по адресу https://m.lotte-autoglobal.net/co/main/popSpltInfoView.do?mode=20; отдельное согласие площадки не получено. Техническая доступность публичного списка не является подтверждением лицензии на данные.

## Выбор покупателем

Поиск с русскими алиасами, фильтры марки, кузова, года, пробега, цены и валюты, сортировки, URL с фильтрами и отдельным автомобилем. Разные валюты не сравниваются напрямую; для ценового фильтра нужна выбранная валюта. Неизвестные значения не проходят заданное ограничение. По умолчанию свежие публикации источника показываются первыми.

В подборку можно сохранить до пяти машин на устройстве, открыть их фото и характеристики, подготовить единый редактируемый запрос со всеми исходными ссылками. Кнопка копирования не отправляет сообщения; телефон и Telegram остаются доступными для личного обращения. Автоматической отправки в CRM нет. Источник цены, дата снимка и необходимость отдельного расчёта доставки, пошлин, утильсбора и услуг явно указаны.

Проверки: `scripts/check-order.mjs` входит в сборку. Проверяются нормализация, исторические ID с префиксом U, отсутствие VIN/ID продавцов, уникальность записей, безопасные фото, фильтры с неизвестными значениями, валюта, лимит подборки, существование элементов и ресурсов страницы.

## Единый каталог и фотографии — 20.10.2026

Покупательский каталог встроен в главную страницу (`#catalog`). В нём единые карточки, поиск, подборка и диалоги для машин поставщиков и агентства. Три переключателя: «Под заказ», «Агентство», «Все автомобили». Обычный экран содержит поиск и марку; дополнительные ограничения, валюты и статусы раскрываются отдельно. Детали источников и дат перенесены под список машин. `order.html` перенаправляет в этот же каталог, сохраняя параметры и ID автомобиля.

Публичные списки фильтруются по наличию реальных фото. Из 81 прежнего объявления агентства скрыты 26 без фото; в базе они сохранены. В каталоге остаются 55 с фото (45 без отметки о продаже, 10 проданных). 4950 поставщицких записей имеют ссылки на фотографии. Справочные модели и прежние дублирующие панели не показываются в основном каталоге.

При сетевой ошибке фото выполняется переход к следующему изображению. Если ни одно изображение не загрузилось, запись временно скрывается до перезагрузки страницы и убирается из выбранной подборки. Подсчёт и выдача обновляются. Серые иллюстрации вместо автомобильных фото не показываются.

Шаблон нового раздела — `catalog-section.html`; `scripts/generate-buyer-section.mjs` вставляет его в `index.html` при сборке. Старый интерфейс изолирован скрытым `#legacy-catalog` для совместимости обработчиков контактной формы, калькулятора, старых ссылок и существующих отдельных страниц; покупатель взаимодействует только с новым разделом. Новый JSON включает нормализованные записи обоих источников и отдельное основание цены: агентская публикация или зарубежный продавец. Рубли, USD, GEL и суммы «от» сохраняются как в источнике; автоматического пересчёта в полную стоимость нет.

Фото сторонних площадок не ретушировались, водяные знаки сохранены. Для дальнейшего оформления подходят собственные снимки или оригиналы поставщика без надписей. Исходные данные и оригиналы не удалены.
