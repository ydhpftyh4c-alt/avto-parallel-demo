# Локальные карточки поставщиков

Обновлено 20.10.2026. Полный импорт всех четырёх платформ не выполнен.

- LOTTE: 4950 уникальных записей из всех 495 страниц публичной выдачи на момент обхода. Первичная выдача содержит максимум пять фото на автомобиль; для полной галереи нужен отдельный запрос каждой карточки.
- mobile.de: 999 уникальных объявлений из 50 доступных страниц общего поиска. Источник показывает более 1,5 млн результатов. Поле `coverage: partial_search_window` обязательно сохраняется: 50 страниц не равны всему каталогу. API объявлений по-прежнему требует отдельного доступа; публичный HTML доступен.
- Encar: главная и оболочка поиска открываются, но список объявлений не загружается; API отвечает страницей `has_been_cr_blocked_AWS.html`.
- Che168: вместо объявлений проверка Tencent EdgeOne. Она не обходится загрузчиком.

## Где редактировать

`vehicle-library/lotte/bmw/6-series/2308483921/` — пример одной машины. Для mobile.de структура такая же. `vehicle-library/index.json` связывает ID, название и папку каждой карточки.

- `vehicle.json` — редактируемые поля автомобиля; повторная загрузка их не перезаписывает.
- `source.json` — исходная запись для сравнения с правками; не редактируйте её.
- `media.json` — вся найденная галерея, URL, имя файла, статус, размер и SHA-256 скачанного оригинала.
- `photos/001.webp`, `002.webp` и далее — оригинальные скачанные снимки. Для mobile.de возможны также JPG и AVIF, формат проверяется по содержимому ответа.
- `edited/001.jpg` или `001.webp` — положите сюда свою замену первого кадра; номер должен совпадать. Можно изменить формат. Не кладите несколько замен одного номера.

Папки создаются заранее для всех записей снимка. Наличие папки не подтверждает завершение загрузки фотографий. Локальные файлы исключены из Git и не публикуются автоматически.

## Загрузка и продолжение

Запускайте команды из корня проекта. Node.js 22.13+ для SQLite, 22+ для остальных команд.

```sh
node scripts/complete-supplier-library.mjs
```

Один раз проходит полные карточки всех записей имеющихся снимков, затем скачивает фотографии. Это не расписание и не импорт отсутствующих объявлений с закрытых площадок. LOTTE: извлекается только основная галерея, без фото похожих машин. mobile.de: галерея привязана к точному ID объявления; код страницы не исполняется. Ссылки и водяные знаки сохраняются. Для фотографий два параллельных запроса, небольшая пауза после каждого; карточки обходятся последовательно. При блокировке, проверке доступа, тайм-ауте или изменении схемы процесс останавливается с причиной. HTTP 404/410 фиксируется отдельно. Уже сохранённые файлы и ручные правки не перезаписываются. Запускать вторую копию во время работы нельзя: действует файл блокировки.

Этап — `vehicle-library/job.json`, текущий проход — `progress.json`. `details_only: true` означает сбор адресов галерей, а не скачивание всех фото. `photos` в этом проходе может равняться нулю при наличии скачанных ранее файлов. `finished_snapshot_pass` означает завершённый проход по имеющемуся снимку, а не полное зеркало всех четырёх сайтов. После перезагрузки компьютера процесс нужно запустить снова; оставшийся файл блокировки удаляйте только после проверки, что старый процесс завершён.

Отдельные команды:

```sh
node scripts/download-supplier-library.mjs --details-only
node scripts/download-supplier-library.mjs --provider=lotte
node scripts/download-supplier-library.mjs --provider=mobile-de --limit=1
node scripts/parse-mobile-public.mjs --pages=50
```

Все команды сетевые, кроме применения правок, базы и сборки. При остановке скачивания сохранённый прогресс позволяет продолжить повторным запуском без повторной загрузки имеющихся файлов.

## Применить правки и полные галереи к сайту

```sh
node scripts/apply-supplier-library.mjs
node scripts/build.mjs
```

Первая команда читает уже найденные полные галереи, отличия `vehicle.json` от `source.json` и замены из `edited/`. Сохраняет публичные накладки в `data/import/listing-overrides.json` и копирует только отредактированные фото в `assets/buyer-photos/<ID>/`. Сам сайт продолжает использовать исходные URL остальных фотографий. `hidden: true` в `vehicle.json` скрывает запись. Источник, постоянный ID и ссылка продавца вручную не переопределяются. Изменения проверяются сборкой. Публикация — отдельный коммит и push; загрузчик сам ничего не отправляет в GitHub.

## SQLite для дальнейшей работы

```sh
node scripts/build-supplier-database.mjs
```

Создаёт `vehicle-library/catalog.sqlite`: таблицы `sources`, `vehicles`, `photos`, индексы марки/года, источника, валюты/цены и полнотекстовый поиск FTS5. Это локальный снимок базы, а не подключённый сервер сайта. Проверяются целостность и внешние ключи. База использует текущие исходные снимки и актуальные на момент команды манифесты фото; повторите команду после завершения загрузки. При миллионах записей потребуется серверный поиск и пагинация: нельзя отправлять всю такую базу одним JSON в телефон покупателя.
