# База автомобилей «Авто || ПараLLель»

Источник данных — предоставленный владельцем экспорт Telegram от 18.10.2026. Здесь **90 записей**, включая отдельные предложения из подборок и неоднозначные групповые предложения. Это не утверждение о 90 уникальных автомобилях в наличии. Неоднозначные повторы не объединены без доказательств.

## Где что лежит

```text
vehicles/
  марка/
    модель/
      tg-номер-сообщения[-вариант]/
        vehicle.json     — карточка, характеристики, цена, статус, история
        sources.json     — публикации и происхождение фотографий
        README.md        — краткое описание записи
        cover.jpg        — обложка, если в экспорте есть фотографии
        photos/001.jpg   — фотографии этой записи
intake/
  needs-review/          — неподписанные альбомы, потерянные ссылки
  cases/                 — публикации о подборе/передаче, не товарные предложения
  news/                  — новости и редакционные подборки, не товары
  channel-notes/         — прочие сообщения и служебные события
INVENTORY.md             — полный реестр с ссылками на папки
import-report.json       — отчёт покрытия всего экспорта
catalog.sqlite           — локальный, пересоздаваемый индекс (не публикуется)
```

Оригинал экспорта целиком сохранён в `../.local-source/telegram-export/`. В `../.local-source/messages.json` — разобранные 827 сообщений. Эти исходники не входят в Git и не размещаются на сайте. Все 618 оригинальных фотографий дополнительно учтены в папках `vehicles` или `intake`. Все 630 миниатюр сохранены в локальном оригинале; они не подменяют исходные фотографии.

## Как редактировать

Главный источник — `vehicle.json` в папке записи. Редактируйте его, затем запускайте `node scripts/build.mjs` из корня проекта. Скрипт автоматически пересоберёт `catalog-data.js` и `dist/`. Не редактируйте `catalog-data.js` вручную.

- `price: null` — сумма не указана; не заменять её нулём.
- `currency` — RUB, USD или GEL; иностранные валюты не пересчитываются автоматически.
- `status: unknown` — наличие нужно уточнить; **не** подтверждённое наличие.
- `status: sold` — в канале найдена связанная отметка о продаже.
- `status_history` и `price_history` сохраняют сообщения-основания; временная акция не заменяет постоянную цену.
- `review_required: true` — запись сохранена в базе, но не публикуется как товар до проверки.
- `record_kind: offer_group` — публикация упоминает несколько машин без достаточных данных для надёжного разделения.
- `specs.year`, `specs.mileage_km` — нормализованные значения; при противоречии источника нужен флаг проверки, а не догадка.
- `sources.json` сохраняет точный текст продавца, в том числе спорные утверждения. Это архив происхождения, а не подтверждение их истинности.

На сайте сейчас 81 запись: 71 с неподтверждённым текущим наличием и 10 проданных в архиве. Девять неоднозначных записей сохранены только в базе. Сайт показывает по 12 карточек за раз. Прямые ссылки восьми ранее опубликованных автомобилей сохранены.

## SQLite и будущая админка

`python scripts/rebuild-database.py` пересоздаёт локальный `data/catalog.sqlite` из JSON и сохранённых сообщений. Библиотека sqlite3 входит в Python. Таблицы: `vehicles`, `messages`, `vehicle_sources`, `prices`, `media`, `intake`. Это удобный индекс и основа переноса в будущую серверную БД, а не второй источник для ручного редактирования. При пересборке прежнее содержимое индекса заменяется; вручную его не редактировать.

Для сайта на GitHub Pages серверная БД не требуется. При появлении админки можно перенести схему и данные в серверное хранилище, сохранив `record_id`, источники и историю. Ни SQLite, ни JSON сами по себе не обеспечивают приём заявок или защищённый доступ администратора.

## Повторный импорт

```sh
python scripts/import-telegram.py --source "путь к экспорту"
```

Нужен Pillow из `scripts/requirements-import.txt`. Обычная команда откажется перезаписывать существующие папки. `--overwrite` разрешает повторный импорт **с заменой ручных правок импортированных карточек**; перед ним сохраните изменения. Правила распознавания — `scripts/import/curation.json`, прежние проверенные тексты восьми карточек — `editorial-overrides.json`. Простое соседство публикаций или сходство названий не считается доказательством идентичности автомобиля.

## Ограничения экспорта

В выгрузке 52 видеовложения помечены «Not included». Видеофайлов в исходной папке нет. Некоторые ответы ссылаются на отсутствующие сообщения; они перечислены в `import-report.json` и не применены к чужим автомобилям. Фотоальбомы без достаточной связи с автомобилем сохранены на проверку. Наличие, юридическая история и фактическое состояние машин не подтверждались.
