# Каталог моделей для импорта

Направления: Китай, Корея, Европа. Сейчас это стартовый справочник из 99 моделей восьми марок, а не полный мировой каталог, склад или подтверждённая возможность ввоза. Подключённых поставщиков: 0.

## Хранение

- `models/<brand>/<model>/model.json` — модель, источник названия, тип кузова; год, двигатель и комплектация выбираются отдельно.
- `supplier-offers/<provider>/<external-id>.json` — конкретная котировка поставщика; создаётся после импорта разрешённой выгрузки.
- `providers/registry.json` — состояние подключений.
- `estimate-contract.json` — требования к будущему расчёту; действующих тарифов и формул пока нет.

Модель, версия автомобиля и предложение продавца — разные сущности. Нельзя вычислять пошлину или утильсбор только по названию модели. У оценки должны сохраняться входные данные, источник курса, дата, версия правил и все составляющие. Неполная оценка остаётся без суммы.

## Источники

Названия сверены 19.10.2026 с каталогами производителей: Geely, Zeekr, BYD, Hyundai, Kia, Volkswagen, Audi, BMW. Ссылка хранится в каждой карточке. Региональный каталог подтверждает название модели, а не доступность в выбранной стране, левый руль, комплектацию или разрешение на экспорт. Фото моделей не получены; используется явно обозначенная общая иллюстрация.

Для mobile.de требуется API-доступ: https://services.mobile.de/manual/index.html . Для Auto.ru требуется токен: https://auto.ru/support/autoru-legal/ru/api.html . Encar при проверке ограничил доступ; обход ограничений не выполнялся. Для Китая поставщик пока не выбран.

## Импорт котировок

`node scripts/import-supplier-feed.mjs --file authorized-export.json`

Вход: объект с массивом `quotes`. Обязательные поля: `provider_id`, `external_id`, `model_id`, `market` (cn/kr/eu), `currency`, `price`, `source_url` (HTTPS), `observed_at` (ISO). Поля `year`, `engine_cc`, `power_kw`, `mileage_km` обязательны, но могут быть null. Идентификаторы состоят из латинских строчных букв, цифр, точек, дефисов и подчёркиваний. Все записи проверяются до сохранения; повторный импорт того же ID обновляет котировку. Историческое хранение и серверный планировщик ещё не подключены.

Импортёр читает локальную выгрузку. Он не парсит сайты, не загружает фото, не публикует котировки на сайте и не подтверждает возможность ввоза. Ключи API должны храниться на сервере, вне GitHub Pages.

Проверка: `node scripts/check-import-data.mjs`. Сборка: `node scripts/build.mjs`.
