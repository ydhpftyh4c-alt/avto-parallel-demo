Очередь и история

РЕЖИМ РАБОТЫ

Настройки

Расписание работает, пока этот сервер включён. Время — московское.

Ночное обновление

Проверка доступа → LOTTE → mobile.de → галереи и фото. Одновременно выполняется одно задание. На границе ночного окна запланированное задание приостанавливается.

Публикация и резервная копия

На сайте этого сервера опубликованные правки видны сразу. Экспорт сохраняет их в проект для последующей сборки и публикации на GitHub Pages.

Резервная копия содержит базу, историю и настройки. Файлы фотографий нужно хранить отдельно.

Автообработка фотографий

Уверенно распознанные знаки LOTTE удаляются, готовое фото заменяется в карточке автоматически. Оригиналы сохраняются.
